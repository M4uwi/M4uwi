### 🚀 Notable Projects

**[SHA Web Portal](https://github.com/M4uwi/WebApp)**

A full-stack web application designed to digitize and streamline health insurance operations for Kenya's Social Health Authority (SHA). It facilitates a secure transition from manual record-keeping to a digital environment by automating healthcare workflows and beneficiary data management.

*Tech stack: Python, Flask, MySQL, HTML/CSS, JavaScript*

**[Social Sentinel](https://github.com/M4uwi/Social-Sentinel))**

A web-based security application that detects and classifies online phishing attempts to protect users from malicious link tactics. It utilizes trained text-classification machine learning models paired with a real-time web interface.

*Tech stack: Python, Scikit-learn, Gradio, Pandas*

**[Spotify Recommendation Engine](https://github.com/M4uwi/Spotify-Song-Recommendation-System-with-Similarity-Index)**

A custom recommendation tool designed to analyze listener preferences and generate personalized song suggestions based on feature similarity. It processes normalized audio feature matrices and uses cosine similarity along with radar chart visual analytics.

*Tech stack: Python, Scikit-learn, NumPy, Plotly Express, Streamlit*

**[Smart Solar Microgrid Controller](https://www.google.com/search?q=https://github.com/M4uwi/smart-solar-microgrid)**

An embedded IoT microgrid management system designed to optimize load distribution and prevent total power blackouts in standalone solar setups. It integrates real-time sensor feedback with intelligent load-prioritization logic on microcontrollers.

*Tech stack: C++, Python, ESP32, Arduino IDE, MQTT*
